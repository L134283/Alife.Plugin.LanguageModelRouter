# 灵枢 - 实时切换语言模型/报错自动切换容灾

## 核心功能

- **💬 一句话让 AI 切换渠道**：在聊天中告诉桌宠「切换到第二组」「切到 deepseek」，AI 自动调用切换函数，无需手动操作
- **🔄 手动一键切换**：UI 面板直接点击按钮切换到任意一组渠道，即刻生效
- **🎯 拖动 / 按钮排序**：在 UI 中拖动渠道卡片左上角「⠿」手柄，或点击卡片右侧「↑/↓」按钮把某个组前移/后移；排在最上方的组即为主渠道（优先使用），容灾按新顺序从上到下执行
- **🛡️ 自动容灾切换**：遭遇 HTTP 429/402/5xx、请求超时、网络错误，或响应体含内容安全检查类错误（如 data_inspection_failed、content_filter）/自定义关键字时，自动切换备用渠道重试
- **🔍 探测可用模型**：点击「探测」按钮拉取 `/v1/models` 获取该组渠道的完整模型列表，下拉选择后自动填入 Model ID
- **⚙️ 自动容灾开关**：可在容灾设置中开启/关闭自动切换，关闭后只使用当前选定组
- **🧠 思维链显示开关**：可实时开启/关闭 reasoning/thinking 等字段到可见内容的转换，关闭后隐藏思维链
- **⚡ 智能思考/非思考切换**（独立开关）：开启后默认非思考模式（回复更快、token 更省），当 AI 需要调用工具、处理群消息、主动监听等复杂任务时自动切回思考模式
  - 非思考模式**显式发送 `{"thinking":{"type":"disabled"}}`**（对齐官方），彻底关闭思维链；可在每组"Extra Body NotThinking"中自定义禁用写法
  - **🔑 自定义关键词触发思考**：配置关键词（逗号/分号/竖线分隔）后，用户消息命中任一关键词即强制走思考模式，适合代码/数学/分析等需要深度推理的场景
- **📋 各组独立配置**：每组可单独设置 Temperature（采样温度）、Reasoning Effort、Extra Headers、Extra Body
- **🖼️ 原生多模态（每组独立开关）**：完全对齐官方 OpenAI 语言模型的多模态写法——开启的组把图片/文件/视频等媒体以 OpenAI 原生 content parts（`image_url`/`file`/`video_url`）随对话发送给模型（模型真正"看得到"），并向 AI 注册 `LoadImage`/`LoadFile`/`LoadVideo` 查看函数（`temp=false` 默认保留入上下文 / `temp=true` 临时单次补全）；纯文本模型组保持关闭，媒体会被剥离为纯文本，不改变原有行为
- **➕ 自由增删渠道组**：可随时添加/删除渠道组（默认最多 12 组，主组不可删），旧版固定 4 组配置自动迁移
- **🔐 API Key 加密存储（可选开关）**：默认以 Windows DPAPI 密文保存（仅当前系统用户可解密）；可在「安全设置」中关闭加密，改为与官方语言模型插件一致的明文保存，便于跨机器迁移/直观查看

## 使用方式

1. 在角色配置中**禁用**「OpenAI语言模型」
2. **启用**「灵枢 - 实时切换语言模型/报错自动切换容灾」
3. 调整渠道顺序：拖动卡片左上角「⠿」手柄，或点击卡片右侧「↑/↓」按钮前移/后移，**最上方的一组即为主渠道**（必填 Endpoint、Model ID、API Key）
4. 其余组为备用渠道，设置组名称（如 deepseek、京东）供 AI 识别
5. 配置保存后**即刻生效**，无需重载

### 聊天中切换

对桌宠说：
- 「切换到第二组」
- 「切到 deepseek」（按组名称匹配）
- 「换到京东」

AI 会调用 SwitchModelGroup 函数直接切换，无需手动操作 UI。

### 手动切换

面板顶部「手动切换」区域点击对应按钮即可。

### 原生多模态（可选，每组独立开关）

1. 在支持多模态输入的渠道组卡片内开启「原生多模态」（如图文模型 gpt-4o；纯文本模型如 deepseek-chat 保持关闭）
2. 保存配置，并在插件面板「重载此插件」一次，完成 `LoadImage`/`LoadFile`/`LoadVideo` 查看函数的注册
3. 开启后，图片/文件/视频等媒体会以 OpenAI 原生 content parts（`image_url`/`file`/`video_url`）随对话发送，让桌宠分析图片/文件/视频即可

### 探测模型

每组 Model ID 下方有绿色「ⓘ 探测第N组」按钮。点击后拉取该渠道 `/v1/models` 接口，成功后显示模型下拉列表，选择即自动填入 Model ID。

### 思维链显示

在「容灾设置」中可勾选「显示思维链」：
- **开启**（默认）：将 SSE 中的 `reasoning_content` / `thinking` 等字段转为可见思维链内容
- **关闭**：丢弃思维链字段，聊天中不显示
- 切换后**实时生效**（影响后续输出；已刷出的内容不会撤回）

## 配置说明

| 字段 | 说明 |
|------|------|
| 组名称 | 给渠道取别名（如 deepseek、京东），AI 可通过名称切换 |
| Endpoint | API 端点 URL，如 `https://api.openai.com/v1` |
| Model ID | 模型标识，如 `gpt-4o`、`deepseek-chat` |
| API Key | 认证密钥，默认以 Windows DPAPI 密文存储（仅当前系统用户可解密）；关闭「加密 API Key 存储」后明文保存（与官方插件一致） |
| 加密 API Key 存储 | 开关：开启=DPAPI 密文保存；关闭=明文保存（与官方插件一致，便于迁移） |
| Temperature | 采样温度，数值（官方 OpenAI 语言模型默认 0.6）；留空则不发送该参数，使用服务端默认值 |
| Reasoning Effort | 推理强度，可选 `low`/`medium`/`high`，留空不设置 |
| Extra Headers | 额外请求头，JSON 格式 |
| Extra Body | 额外请求体，JSON 格式 |
| 原生多模态 | 每组独立开关：开启后该组以 OpenAI 原生 content parts（image_url/file/video_url）发送媒体并开放 Load 系函数；纯文本模型组保持关闭 |
| 错误关键字 | 响应体含此关键字时触发切换，逗号分隔（内容安全检查类错误已内置，无需配置） |
| 启用自动容灾 | 开启后当前组失败自动切换备用渠道 |
| 优先主渠道 | 每次对话优先尝试主渠道，容灾全程静默 |
| 显示思维链 | 是否将 reasoning/thinking 转为可见内容，默认开启 |
| 重试间隔 | 切换前等待时间（毫秒），默认 1000ms |
| 请求超时 | 单次渠道请求超时上限（毫秒），默认 30000ms。渠道挂起/无响应时按此时间快速容灾切换；设为 0 保留 100 秒兜底 |
| 流空闲超时 | 已建立连接但长时间未收到任何数据视为异常（毫秒，默认 0=关闭）。防止渠道返回 200 后流挂起导致永久等待 |
| 忽略 TLS 证书校验 | 默认开启以兼容自签名/证书异常渠道；关闭后走系统证书校验更安全，但自签名证书渠道将无法连接 |
